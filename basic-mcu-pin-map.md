# Basic MCU Pin Map (Example)

| Logical Function   | MCU Pin | Notes                     |
|--------------------|---------|---------------------------|
| DOOR_SENSOR        | GPIO12  | Input, pulled-up          |
| TEMP_SENSOR        | GPIO33  | Analog input              |
| COMPRESSOR_RELAY   | GPIO25  | Output, active-high       |
| STATUS_LED         | GPIO2   | Output                    |
| UART_TX            | GPIO1   | Serial TX                 |
| UART_RX            | GPIO3   | Serial RX                 |
| I2C_SDA            | GPIO21  | I2C data                  |
| I2C_SCL            | GPIO22  | I2C clock                 |
